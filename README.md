# TP - Portfolio / Galería de Ilustraciones

Este repositorio contiene la primera entrega del trabajo práctico, estructurado con páginas en HTML5 y estilos personalizados en CSS. El sitio web incluye una página principal (`index.html`), una sección de ilustraciones (`ilustraciones.html`) y un formulario de contacto (`contacto.html`), acompañados de sus respectivas carpetas de recursos gráficos y tipografías.

## 🛠️ Detalles Técnicos
- **Editor de código:** Visual Studio Code
- **Resolución de pantalla / Área de trabajo:** 1920 x 1080 px

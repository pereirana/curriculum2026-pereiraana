# Descripción del Proyecto

Este es el primer trabajo práctico para la materia **Computación III**. El objetivo principal de este desarrollo fue poner en práctica y consolidar los conocimientos vistos en clase mediante el uso de **HTML5, CSS3 y Flexbox**, aplicados a la maquetación y diseño de un currículum vitae web interactivo.


## Estructura de la Página

En este proyecto busqué construir una identidad visual propia y coherente mediante una cuidada selección cromática, la jerarquización tipográfica y la sistematización de títulos y misceláneas gráficas. La página inicia con una barra de navegación que organiza los apartados de inicio, sobre mí y proyectos.

A medida que el usuario navega por la web, la sección "Sobre mí" se presenta de manera interactiva a través de una pequeña animación en scroll con degradé, la cual da paso a una sintética introducción sobre mi perfil creativo, experiencia laboral y trayectoria académica. A su vez, el cuerpo del trabajo integra un desglose visual de mis habilidades y el software que manejo mediante íconos temáticos, culminando en un pie de página que invita a seguir explorando mi trabajo en plataformas externas como Behance e Instagram.

## Información Técnica

- *Tecnologías utilizadas:* HTML5, CSS3 (layout maquetado con Flexbox).
- *Recursos visuales y animaciones:* Transiciones CSS, GIFs animados e íconos gráficos.
- *Editor de código:* Visual Studio Code.
- *Tamaño de pantalla:*1920x1080

## Algunas (muchas) complicaciones... :)
En el proceso de realización, el aprendizaje fue en gran medida autodidacta y representó un desafío comprender el funcionamiento de propiedades como padding y margin. Por momentos dependí bastante de ellas para alcanzar el maquetado deseado. Con más tiempo de desarrollo, me habría gustado conectar la navegación hacia secciones externas e incorporar un número mayor de ilustraciones.
